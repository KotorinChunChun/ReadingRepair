## 訂正待ち

大粒径は登録時点ではオオリュウケイです。一次資料の表記と独立2モデルの新判定はダイリュウケイを支持しています。

水収支は登録時点ではスイシュウシです。応用地質用語集の水収支、環境省の水収支法の読みと、全対象文脈を使った独立2モデルの新判定はミズシュウシを支持しています。この推奨を、別の読みが許容されないことの証明とは扱いません。

いずれも実辞書の訂正と、同じ元文章による訂正前後の音声/native解析の確認が終わっていないため、`provisional.dic`と`words.json`から外しています。旧記録を提案読みに書き換えて、検証済みと扱うことはしません。2026-11-06の再照合では新しい登録済み追加はなく、登録時点snapshotは前版と同じ317語です。
