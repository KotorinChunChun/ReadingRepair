# ReadingRepair v0.0.5 実装・検証

公開 v0.0.4 を基準に、TranscriptionServer対応とVoiSona Talk API中継の実装を統合する。同梱SQLiteは公式Windows x64配布物を固定ハッシュで照合して更新する。

Pythonとデスクトップの回帰試験を行い、生成した配布物で補正なし合成・中継・文字起こしを確認する。公開後にKotorinToysの版定義を同期し、現在ユーザーの導入版を入れ替えて設定・履歴・辞書の保持を確認する。

## 配布前の検証

- Python回帰試験163件、初回導入資料5件、導入補助12件は成功。
- CLIから更新した隔離辞書がWPFの辞書画面に反映されることを16項目で確認した。通常のVoiSona辞書は検証による更新前後の比較対象として使用する。
- 公式SQLite ZIPのSHA3-256と、同梱CLIがSQLで取得した3.54.1を確認した。ZIPの禁止パスと既知の秘密値の混入検査に合格した。
- ローカル中継経由でVoiSona Talkが合成した確認用WAVを、TranscriptionServer v0.1.21（whisper/base）とローカルWhisperで文字起こしした。両方とも「明日の天気は晴れです」となった。
- 配布EXEの起動、無表示の管理起動、表示要求、二重起動抑止、正常終了を確認した。
