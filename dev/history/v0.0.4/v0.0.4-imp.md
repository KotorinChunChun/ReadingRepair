# ReadingRepair v0.0.4 実装と検証

- 公開済みmainを基点に、原稿と音声波形の図柄を作成する。複数サイズのICOをWPF・EXE・セットアップで使う。
- 自己完結ZIPとセットアップを生成し、版、アイコン、主要画面、管理CLIを検証する。
- GitHubへ公開し、取得した配布物をローカルの候補と照合する。

## 検証結果

- 配布用EXEに埋め込まれたアイコン10サイズを元のICOとバイト単位で照合した。WPFの起動試験でもウィンドウがアイコンを読み込んだ。
- Pythonの154テストが成功した。自己完結ZIPをビルドし、同梱CLIで合成・文字起こし・入力エラーを確認した。
- セットアップを生成し、EXEとセットアップの両方で元のICOの10サイズが一致した。ZIPとセットアップに含めたアプリEXEのSHA-256も一致した。
- 起動時のWPFアイコン読み込み、管理CLIでの再表示と正常停止、保存済み録画で変換画面の表示を確認した。通常環境へのインストールは未実施。
- ZIPのファイル構成と既知の秘密値の混入を検査した。配布用SHA-256はリリースに同梱する。
