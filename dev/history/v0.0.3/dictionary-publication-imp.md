# 辞書の暫定公開 計画・報告

## 実装前の計画

利用者の明示的な辞書公開依頼に基づき、KotorinChunChun/ReadingRepairへ辞書データだけを追加する。親作業と別のcloneとブランチを使い、元のアプリ・実辞書・原稿・処理状態は変更しない。コードやアプリ版は変更しない。

確認済みの追加317語のnative形式exportを固定し、そのままの登録時点記録を保存する。大粒径は資料と独立2モデルの新判定でダイリュウケイが採用された一方、実登録はオオリュウケイのままで訂正前後の音声再測定が終わっていない。この1語を分離した316語の暫定利用版も作り、訂正待ち情報と違いを明示する。初期5語、未確認追加、保留候補を利用版へ混ぜない。

公開対象はnative行、表記・読み・アクセント、件数・SHA、短い説明と既知の保留情報に限る。原文・解説・音声・認証・設定・ローカルパス・生ログ・モデルの応答は含めない。多数決/native解析の一致を人の聴取合格としない。

既存native辞書parserで件数・一意性・差分・アクセントとハッシュを確認し、公開ファイル一覧と秘匿情報の混入を点検する。固定した入力と公開物の対応をローカルで確認後、日本語コミットで専用ブランチへpushし、PRと直接取得できる辞書URLを提示する。

## 実施・検証結果

確認済み追加317行をそのまま保存し、訂正待ちの大粒径1語を除いた316行と316語のAPI用JSONを作成した。native行の順序・属性・アクセントを保持し、原文・音声・設定・認証・初期5語は公開対象に含めていない。

既存backend/lab.pyのdictionary_snapshotでnative両版とJSONを読み取り、317/316/316件と表記一意性を確認した。316語の2形式が同じ順序・表記・読みであること、元exportとの317行完全一致、追加全件の登録成功・native一致記録・独立2票以上、公開ファイルのSHA-256を検証した。登録時点記録のSHA-256はfb69ac7a73b2ad36870e7dd730dfe3a41eee43e31bd7a98c2942f533488fc29b。元アプリ・辞書・処理状態を変更していない。

公開前のファイル一覧・秘匿情報・リンク・JSON・差分を点検した。ライセンスへの相対リンク1箇所を修正後に再検証し、すべて成功した。辞書ディレクトリはLFに固定し、Gitのstage済みblobのSHA-256もmanifestと一致した。アプリコードを変更していないため全アプリビルドは行わず、既存parserによるデータ検証を対象にした。
