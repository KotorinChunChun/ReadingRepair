# ReadingRepair v0.0.1 実装計画・報告

作成日: 2026-11-04。対象: [要求](v0.0.1-req.md)。作業ブランチ: feature/v0.0.1。

## 0 事前確認

元アプリはproject_root/.env、src/CodexChat.psm1、旧venvと作業ツリー構造へ依存。移動先親はfeature/full-refactoringで他の未コミット変更あり。親の既存差分を変更しない。GitHub認証は通常権限環境で有効。ReadingRepairリポジトリは未作成。

## 1 フェーズと完了条件

1. 独立した正本・版別資料・Gitの作成。許可リストで追跡ソースのみ抽出する。
2. backend、Desktop、Registrationを独立配置。外部設定、モデル、LLM CLIの境界を整理。TTS/辞書契約とHTTP WAVアダプターを実装。既存試験とエンジン差分試験を通す。
3. ReadingRepair名・窓タイトル・設定・起動・管理IPC・依存診断・ユーザーガイドを整備し、隔離CLI/実プロセスで確認する。
4. PyInstaller backendと自己完結.NETアプリを配布し、公開物を走査。別フォルダーへ展開して旧ソースなしのCLI/音声動作を確認する。
5. 独立リポジトリのPush、v0.0.1 Release、再取得ハッシュ検証。元の入口を移動先へ案内し、履歴を保持する。

## 2 設計

backend/tts_backends.pyがエンジン選択、能力、合成、解析、辞書スナップショット・競合確認・登録を仲介する。VoiSonaは既存APIとUIAを維持。HTTP WAVは外部.envのendpoint/body/bearerを使い、エンジン別JSON辞書を音声化前へ適用。解析非対応は理由を保存し、Whisper・複数LLMで判断する。秘密はプロンプト・公開物へ含めない。

設定と実行履歴はLocalAppData/ReadingRepair、開発検証の証跡は本版logs。起動場所に依存せず、配布時はbackend/ReadingRepair.Backend.exeを優先する。

## 3 検証

既存回帰、HTTPローカル検証サーバーでの登録前後合成とエラー/競合/秘密保護、VoiSona接続・既登録語の再合成、WPFとヘルパービルド、管理IPC・別配置の配布物実行、秘密値・ユーザー記録の混入検査、公開アセット再取得を行う。人間の聴取は自動試験と区別する。

## 4 実装結果

P2: 既存114件と新規HTTP7件の計121件が成功。WPFと登録ヘルパーのビルドは警告0・エラー0、登録ヘルパーself-testは5件成功。VoiSona REST API・現在の辞書35件・Codex・Whisperモデル・両APIキー設定をdoctorで確認。独立venvから12.965秒の実音声を生成し、実Whisperで文字起こしできた。

P3: CLIから実WPFプロセスを専用設定で起動し、無表示起動、契約2、誤PID拒否、show、重複時の既存PID保持、正常stopを確認。画面初期化と可視ボタン8個のツールチップをWPFツリーから確認。実行タイトルはReadingRepair - ver 0.0.1。

追加対応: 新規venvの依存解決がPyAV 19.0.2を選び、faster-whisper 1.2.1のmetadata_errors引数と不整合で文字起こしが失敗した。PyAV 16.0.1へ固定し、同じ実音声の文字起こし成功を確認した。[上流報告](https://github.com/SYSTRAN/faster-whisper/issues/1589)。HTTPエンジンは発音解析非対応であるため、ログ・判断・補助差分の全経路で非対応を扱う。HTTPエラー応答を閉じて通信資源の残留を防ぐ。

生ログ: logs/independent-before.wav、independent-transcript.json、desktop/management.json、desktop/smoke.json（Git対象外）。


P4の事前検証: ZIPをTEMPへ別配置して、同梱backendのdoctor、実Whisper文字起こし、同梱WPFの管理IPC・窓タイトル・ボタン説明が成功。旧ソース/venvはロードせず、外部のTTS設定とWhisperモデルのみを使用。直接CLIの日本語がWindowsの既定CP932へ依存する問題を検出し、標準入出力をUTF-8へ固定して回帰試験を追加。HTTP辞書は英数字の全半角を照合しつつ、無関係な文字を変えないことも追加検証。Python回帰は123件成功。

実接続一巡: 改行を含む原文で一次LLM、VoiSona、Whisper、登録候補チェック、再生成、同基準評価、HTML生成がcompleted。前88点・後90点、CERは両方2.86%。既登録読みがTTS解析と一致し、新規登録は0件。値の一部がWhisperで「ー体」となった差を保持し、100点とは報告していない。生データはlogs/live/。実辞書は35件を維持。

履歴移行: 元v0.4.0のアプリ履歴7件をLocalAppData/ReadingRepair/runsへコピー。原文とWAVのSHA-256一致を確認。元ジョブとmanifestをmigration-originalへ保持し、参照先だけを独立アプリへ更新。元履歴は削除せず、公開物にも含めない。
